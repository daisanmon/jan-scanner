# Seller画面との料金検証（2026-08-28）

## 条件

- 日本の自社Sellerアカウント
- 日本語UI、中国市場、現在の出品方式
- Seller画面のサイズ別「中国表示可能価格」と「収入見込」を閲覧のみで確認
- アプリ計算: 出品手数料5%（最低700円、上限4,230円）、運営費の価格帯、送金手数料1%を各規則どおり丸める

## 実装上の扱い

- 検証済み料金ポリシーの対象を「スニーカー」に限定する。
- Crocs、clog、sandal、slipper、slide、boot等、タイトルまたはブランドから明確に対象外と分かる商品は「要確認」とし、概算収入と仕入れ上限を算出しない。
- 商品カテゴリの正式なAPI項目が確認できるまでは、この判定は安全策であり完全なカテゴリー判定ではない。
- 公開APIにはSeller画面の「収入見込」フィールドが確認できないため、正式仕様は [問い合わせ文案](estimated-income-support-request.md) でPOIZONへ確認する。
